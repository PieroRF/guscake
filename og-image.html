Imagen para redes / buscadores

Descarga los dos archivos, guárdalos en la carpeta img/ y sube los cambios.

  1. Presiona los dos botones ⬇ (se descargan og-image.png y favicon.png).
  2. Mueve ambos archivos a la carpeta img/ del proyecto.
  3. Sube los cambios: git add img/og-image.png img/favicon.png index.html mayoristas.html site.webmanifest → git commit → git push.
  4. En Google Search Console pide reindexar https://guscake.cl/.
